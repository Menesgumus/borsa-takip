# Borsa Takip

Bu proje Borsa Takip uygulamasının root dizinidir. 

## Dizin Yapısı

- `backend/`: FastAPI tabanlı arka uç.
- `frontend/`: Next.js tabanlı ön uç.
- `infra/`: Docker, Compose ve CI dosyaları.
- `docs/`: Mimari ve operasyonel belgeler.
- `scripts/`: Geliştirme yardımcı komutları.

## Geliştirme Ortamı

Bu proje `pnpm` (frontend) ve `uv` (backend) kullanır.

- Node.js >= 22.0
- Python >= 3.12
- Docker & Docker Compose
